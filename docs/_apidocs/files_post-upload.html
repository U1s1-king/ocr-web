    上传文件 (Upload)

    Method: POST

    Endpoint:

    /api/v1/files

    请求参数

    • Content-Type: multipart/form-data
    • 表单中必须且只能包含一个文件
    • 文件大小必须严格小于 10 MiB
    • 服务端计算文件内容的 SHA-256 作为 hash
    • 同一内容重复上传不会产生新记录，直接返回已有 fileId

    表单字段：

    file=<二进制文件>

    响应示例

    首次上传返回 201：

    {
  "data": {
    "fileId": 1,
    "hash": "623099066de4cbef710c0f36302f31f49e9e607654f879ace5cd536ab16833b7",
    "uTime": 1794208350,
    "name": "高一数学第一次月考答题卡.pdf",
    "suffix": "pdf"
  }
}

    重复上传同一内容返回 200，结构相同；已有非空文件名保持不变。

    fileId 用于 检查试卷 或 批改考试。

    存储

    文件按 hash 分级保存：

    data/files/ab/cd/abcdef...

    文件名、后缀、hash 和时间保存在独立的 data/files.db：

    字段 说明
    id 文件 id
    hash SHA-256
    u_time Unix 秒级时间戳
    name 原始文件名
    suffix 小写后缀名，不带点

    name 使用 simple 分词器建立全文索引，支持中文和拼音搜索；
    suffix 使用普通索引，按完整值匹配。

    错误

    • 400 / INVALID_FORM_DATA：不是合法的 multipart 表单
    • 400 / INVALID_FILE_COUNT：文件数量不是 1
    • 400 / INVALID_FILE_NAME：文件名为空
    • 413 / FILE_TOO_LARGE：文件大小达到或超过 10 MiB
