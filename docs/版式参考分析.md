## 1. 统一结构

正规高考答题卡不是「一列题目直接向下排」，而是固定分区：

```text
┌────────────────────────────────────────────┐
│ 考试名称 / 科目答题卡                        │
│ 姓名、准考证号、考场号、座位号   贴条形码区   │
│ 注意事项 / 填涂样例 / 缺考标记                │
├────────────────────────────────────────────┤
│ 一、选择题（按 2B 填涂网格排）                 │
├────────────────────────────────────────────┤
│ 二、非选择题（填空题 / 解答题，大块作答区）     │
├────────────────────────────────────────────┤
│ 题号 / 得分表                                 │
│ 第 1 面（共 2 面）                            │
└────────────────────────────────────────────┘
```

背面通常重复：

- 考试名称 / 科目
- 姓名、准考证号等考生信息
- 注意事项
- 四角定位块
- 大题作答区
- 页脚「第 2 面（共 2 面）」

## 2. A4 与 A3

| 纸型 | 常见科目 | 结构 |
| --- | --- | --- |
| A4 | 英语、部分选考科目 | 上方选择/填空，下方主观题；背面作文或继续作答 |
| A3 横版 | 语文、数学、物理、历史、政治 | 正面选择题 + 填空/主观题；背面大块主观题；四角定位块 |
| 8K 横版 | 部分学校月考/联考 | 尺寸小于 A3，栏距和字号相应缩小 |

## 3. 数学 A3 关键特征

参考 `ref-13` / `ref-14`：

- 正面：
  - 标题、考生信息、条形码区、注意事项
  - 选择题网格，通常 2 栏或全宽多列
  - 填空题
  - 大面积主观题区
  - 底部题号/得分栏
- 背面：
  - 重复考生信息和注意事项
  - 每个大题独立、较大的作答区域
  - 背面通常 2–3 栏，或按题量分块

当前生成器已加入：

- 正反面页脚 `第 1/2 面（共 2 面）`
- 正面题号/得分栏
- 背面复制正面表头、注意事项、四角定位块
- 数学/理科背面三栏，主观题按题量分到两面

## 4. 语文 / 英语

- 语文背面：整页作文格，格子数量、行距固定。
- 英语背面：应用文 + 读后续写两个大块，作文区域通常为横线格。
- 这两类不能沿用数学三栏。

## 5. 条形码

- 答题卡条形码区约 **50 × 20mm**，位于正面右上角。
- 条形码左右必须保留静区，当前渲染已加 `margin: 10`。
- XP-420B 标签打印使用 TSPL：
  - Code128
  - 标签尺寸与条形码区一致
  - 203dpi，按 8 dots/mm 换算坐标
