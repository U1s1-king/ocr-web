# 开源方案调研与接口覆盖清单

调研时间：2026-11-19。目标：答题卡「类似 PS 的自由排版」+「对标高考答题卡」+「自动化出卡」，
并核对 `/api/v1` 文档与当前页面的覆盖情况。

**结论：没有可以直接替换本项目的成熟开源项目。** 真正能加速的是：

1. **高考版式规范**：以 AnswerSheetMaker（MIT）为标准答案，移植/对照它的表头、涂卡格、
   主观题框、作文格、定位点、页码等画法与毫米尺寸；
2. **自由排版编辑器**：不自己造轮子，用成熟 Canvas/DOM 操控库（见下）；
3. **自动化出卡**：保留我们已有的「参数化模板 + 排版引擎」，把模板规格改成高考真实结构。

### PS 类编辑器选型

| 方案 | 许可 | 优点 | 代价 |
|---|---|---|---|
| **react-moveable + Selecto + react-guides** | MIT | 直接叠加在现有 mm DOM 渲染器上；拖/缩/旋转/多选/吸附/分组/对齐线齐全，改造量最小 | 图层、标尺需自己补，导出 PDF 仍用现有打印 |
| **Fabric.js** | MIT | 真正 Canvas 对象模型：图层、多选、变换、序列化、SVG 导出，最接近 PS | 要把现有渲染器迁到 Canvas，文本编辑/打印校验成本高 |
| Konva + react-konva | MIT | React 场景图、Transformer 成熟 | 同样需要迁移渲染层 |
| tldraw | 自定义许可 | 体验最好 | 商用需授权/水印，不适合比赛项目直接依赖 |

**建议**：先上 **react-moveable + Selecto**（MIT）把现有精调页升级成 PS 手感：多选、框选、
旋转、对齐吸附、图层树、标尺、快捷键、复制粘贴、层级调整；保留现有 mm DOM 渲染与打印，
保证识别坐标不漂移。若后续需要真正的无限画布/复杂图层，再评估迁移 Fabric.js。

## 二、接口覆盖清单（对照 `/api/v1` 文档）

| 接口 | 当前页面/功能 | 状态 |
|---|---|---|
| `GET /logs` | 接口日志页（桌面/移动） | ✅ |
| `POST/GET/PUT/DELETE /exam-batches` | 考试批次页（桌面/移动） | ✅ |
| `GET /exam-results`、`GET /exam-results/{id}` | 成绩分析列表 ✅；**桌面缺成绩详情页**（`/results/:id` 路由缺失，考试详情里的链接会 404） | ⚠️ 补页 |
| `POST/GET/DELETE /exams`、`GET /exams/{id}`、`GET /exams/{id}/results` | 考试列表/新建/详情 | ✅（**桌面无删除考试按钮**，移动端有） |
| `POST /exams/{id}/grade` | 移动端批量批改使用；桌面「上传批改」仍调用旧 `POST /exams/check` | ⚠️ 桌面改为 grade / papers check |
| `POST /files`、`GET /files/search` | 文件库 | ✅ |
| `POST/GET/PUT/DELETE /papers`、`/papers/{id}/answers` | 模板工坊 / 精调页保存 | ✅（**缺独立答案键编辑面板**） |
| `POST /papers/{id}/check` | 移动端试卷详情、诊断页使用 | ⚠️ 桌面检查页需切到该接口 |
| `GET /reviews`、`GET /reviews/{id}`、`GET /reviews/{id}/image`、`PUT /reviews/{id}` | 复核列表/详情/原图/判定 | ✅ |
| `POST/PUT/DELETE /students/batch`、`GET /students` | 名册批量增删改 ✅；列表仍读本机 localStorage，未用 `GET /students` | ⚠️ 列表改接口 + 本机兜底 |
| `GET /templates`、`GET /templates/{id}` | 模板工坊左栏「后端模板」 | ✅ |

**待补页面/按钮**：桌面成绩详情页、桌面删除考试、桌面批量批改（grade）、答案键编辑面板、
学生列表接新接口、桌面检查页接口切换。

## 三、下一步实施顺序（建议）

1. **接口补页**（1 轮）：修桌面 `/results/:id`、删除考试、grade 批改、答案键面板、学生列表；
2. **高考模板重建**（重点）：以 AnswerSheetMaker 的版式为基准，重做 54 份模板的
   表头/定位点/涂卡格/主观题框/作文格/页码，并增加「标准高考版 / 紧凑版」；
3. **PS 编辑器升级**：react-moveable + Selecto + 图层/标尺/吸附/多选/撤销；
4. **自动化增强**：模板 DSL（参数化出卡）+ 一键批量生成同规格答题卡；
5. 后端可用后再联调（用户已说明暂不测试）。
