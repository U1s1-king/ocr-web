    批量检查试卷 (Check Batch)

    Method: POST

    Endpoint:

    /api/v1/papers/{id}/check

    一次检查多个已经上传的答题卡文件。试卷 id 放在路径里，文件 id 放在请求体中。

    路径参数

    参数 类型 说明
    id Integer 要检查的试卷 id

    请求参数

    Body (JSON):

    字段 类型 必填 说明
    fileIds Integer[] 是 上传文件 id 数组，1–50 个，不能重复

    示例：

    {
  "fileIds": [1, 2, 3]
}

    fileIds 来自 上传文件 返回的 data.fileId。

    批量语义

    • 一份试卷只解析一次；
    • 按 fileIds 顺序逐个检查；
    • 单个文件失败不会中断整个批次；
    • 单个文件失败时，对应结果包含 success: false、code 和 error；
    • total、successCount、failureCount 是本次批次的汇总；
    • 整个请求只有在试卷不存在、试卷为空或试卷配置损坏时才直接返回错误。

    错误

    整批错误：

    • 400 / VALIDATION_ERROR：fileIds 不合法
    • 400 / INVALID_JSON：请求体不是合法 JSON
    • 404 / PAPER_NOT_FOUND：试卷不存在
    • 409 / PAPER_EMPTY：试卷还没有配置内容
    • 422 / PAPER_CONFIG_INVALID：已保存的试卷 JSON 不合法
    • 415 / UNSUPPORTED_MEDIA_TYPE：不是 application/json

    单个文件结果中的错误：

    • FILE_NOT_FOUND：文件 id 不存在或磁盘文件丢失
    • CHECK_FAILED：图片定位或识别失败
