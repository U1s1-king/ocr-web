# 高考试卷/答题卡版式参考

> 调研日期：2026-11-23  
> 用途：前端统一试卷页的试卷渲染样式依据。

## 一、答题卡尺寸（有官方说明）

湖北省教育考试院《2026年高考温馨提示（三）：规范答题，避免失分》明确：

- 高考语文、数学，学业水平选择性考试物理、历史、思想政治，技能高考文化综合：**A3 幅面答题卡**
- 高考外语，学业水平选择性考试其他科目：**A4 幅面答题卡**

答题卡主要区域：

1. 考生信息区
   - 姓名、准考证号、考场号、座位号
   - 贴条形码区
   - 注意事项
2. 答题区域
   - 选择题填涂区（2B 铅笔）
   - 非选择题书写区（0.5mm 黑色签字笔）
3. 图像定位点
   - 选择题定位点
   - 非选择题定位点

来源：<https://www.hbea.edu.cn/html/2026-05/15866.html>

## 二、试卷纸尺寸

国内学校考试常用 **8 开（8K）** 试卷纸。

行业纸张规格参考：

- 正 8 开白料：**270mm × 390mm**
- 成品：**260mm × 370mm**
- A3：**297mm × 420mm**

来源：<http://www.sdkxzy.com/sjzyz/8ksjz.html>

高考/学校试卷常见做法：

- 8K 或 A3 横版
- 双面印刷
- 中间折叠
- 左/右侧密封线
- 页脚“第 X 页 共 X 页”
- 试卷类型 A/B
- 姓名、准考证号、考场号、座位号
- 注意事项框
- 第Ⅰ卷选择题 / 第Ⅱ卷非选择题

> 说明：全国没有统一强制“高考试卷必须某一种纸”的公开标准；不同省份、印刷厂会使用 A3、8K 等不同规格。前端因此提供 A3 / 8K / A4 三种预设。

## 三、前端实现

统一试卷页 `/#/papers/bundle` 的「试卷」视图已改为高考风格：

- A3 横版默认
- 可选 8K 横版 / A4 纵版
- 顶部“绝密★启用前”
- 标题区“2026 年普通高等学校招生全国统一考试（模拟）”
- 科目、考试名称、时长、满分
- 考生信息行：姓名、准考证号、考场号、座位号
- 试卷类型 A/B
- 注意事项框
- 双栏题面
- 题号、题干、选项 A/B/C/D、分值
- 页脚“第 1 页 / 共 X 页”
- 打印时按选择的纸型设置 `@page`

答题卡视图仍按 A4/A3 版面绘制，题区、选项框、定位块单独渲染。

## 五、答题卡版式调整

根据官方答题卡样张：

- **A3 卡**：左侧/上方为选择题填涂区，右侧及剩余空间为非选择题书写区；非选择题通常分成 2–3 个纵向栏
- **A4 卡**：上方为选择题填涂区，下方为非选择题书写区
- 正反面都有考生信息；背面通常也有姓名/座位号
- 选择题与主观题都用图像定位点包围

前端 `CardStudio` 的 A3 模板已调整为：

- 左侧选择题填涂区（双列排布）
- 右侧主观题区（3 列）
- 表头、条形码、注意事项保持通栏
- A4 仍按“上方选择题、下方主观题”排版

BarcodeStudio 已增加：

- 画布缩放（75%–400%）
- 拖动组件
- 选中组件后拖动右下/右边/下边调整宽高
- 桌面和移动端都支持

## 六、双面强制规则（2026-11-23）

- 所有答题卡默认双面，不提供关闭双面的开关
- A4 答题卡同样生成正面 + 背面
- A3 / A4 都保留四角定位点和正反面考生信息
- 试卷默认双面：第 1 页正面，第 2 页背面
- 科目化背面：
  - 语文：作文格
  - 英语：应用文 + 读后续写
  - 数学 / 物理 / 化学 / 生物：解答题栏
  - 历史 / 地理 / 政治：主观题栏
- 旧试卷打开时如果没有背面，会自动补一页科目化背面

### 预览交互

- 不做单面/双面开关
- 只提供「正面 / 背面」切换
- 试卷页和答题卡页都默认双面
- A4 也只做双面
- 编辑旧单面试卷时自动补背面
