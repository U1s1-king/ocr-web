# 移动端版式说明（vivo 参照落地）

参照图：`docs/design-reference/1.jpg ~ 4.jpg`（vivo 应用商店「表盘 / Today / 我的 / 应用」）。
实现时只借用**排版版式**，颜色与组件仍走项目自己的 `--mo-*` 设计令牌。

## 对照关系

| 参照图 | 页面 | 关键版式 |
|---|---|---|
| `2.jpg` Today | 首页 `/#/m` | 日期小字 + 36px 大标题；全宽渐变行动卡（拍照 / 上传）；数据概览卡；最近成绩排行榜行；全部功能 4 列图标网格 |
| `4.jpg` 应用 | 试卷页 `/#/m/papers` | 大标题；分段胶囊（我的试卷 / 答题卡模板）；「推荐精选」横滑模板卡（露下一张）；体系分类胶囊；全部模板排行榜行 + 右侧「使用」胶囊 |
| `1.jpg` 表盘 | 考试页 `/#/m/exams` | 精选专题横滑大卡（新建考试 / 批量批改 / 考试批次）；分段胶囊（全部 / 待批改 / 已出分）；搜索白胶囊；考试排行榜行 + 「去批改 / 查看」胶囊 |
| `3.jpg` 我的 | 我的页 `/#/m/mine` | 大标题 + 资料行（头像 / 昵称 / 数据摘要 / 编辑）；连接状态卡；5 图标快捷卡；8 图标数据工具卡；分组设置列表 |

底部沿用参照的**胶囊 Dock + 右侧搜索 FAB**（4 个 Tab：首页 / 考试 / 学生 / 我的）。

## 版式组件（`src/styles/mobile.css`）

- `.mo-display` / `.mo-date`：参照页的大标题与日期
- `.mo-feed` / `.mo-feed-dark` / `.mo-feed-light`：全宽行动卡（Today 流）
- `.mo-carousel` + `.mo-feature-card` / `.mo-template-card`：横滑大卡，默认露下一张促滑
- `.mo-rank-num` / `.mo-rank-thumb` / `.mo-rank-title` / `.mo-rank-sub`：排行榜行
- `.mo-chip-row`：分类胶囊横滑行
- `.mo-icon-grid` / `.mo-icon-grid-item` / `.mo-icon-grid-ico`：白色分组卡里的 4 列图标
- 分段胶囊继续用 `.mo-seg`，小按钮用 `.mo-btn-soft`（参照「获取」）

## 数据与跳转

- 试卷页「答题卡模板」直接读取 `src/lib/card/catalog.ts` 的 54 份内置模板，点击后跳
  `/#/papers/studio?tpl=<模板id>`，模板工坊会自动选好对应模板。
- 首页/考试页无后端数据时保留骨架与空状态，服务状态错误用统一的 `ErrorBar` 展示，不阻断版式。
- 所有横向卡都支持触屏滑动与 `scroll-snap`，页面底部为 Dock 预留 112px 安全滚动区。


## 视觉升级（2026-11 第二版）

- 参照 iOS 原生 + Voyager / Memos 的克制卡片：毛玻璃 Dock、20px 圆角、轻阴影、暖白底；
- 主色改为与印章 logo 一致的 **印章红 `#a6342a`**，canvas 切到暖白 `#f5f2ee`；
- Ant Design Mobile 接入为交互组件（Dialog 等），并通过 `--adm-*` 变量对齐品牌令牌；
- `react-guides` 不兼容 React 19，已移除，参考线改用 Moveable 内置能力。


## 视觉特效（2026-11 第三版）

- 首页：`mh-hero` 英雄卡（极光 + 粒子 + 流光标题 + 扫描状态 + 彩带按钮）、滚动字幕、数据冲刺卡、
  模板橱窗横滑卡、8 个模块 3D 倾斜卡；
- 其它页面：`Page` 统一页头光晕 + 流光标题 + 动态下划线；卡片入场/扫光；Dock 玻璃与呼吸线；
- 开屏：粒子 + 轨道 + 彩带，2.25s 后爆开退场；
- 动画库：framer-motion、tsparticles、canvas-confetti；动效集中在 `src/styles/fx.css`。


## 水墨版视觉（2026-11 第四版）

- 首页改为墨底朱砂英雄卡 + SVG 笔触；标题、按钮、统计卡统一纸色/墨色；
- 页面背景：宣纸 + 淡墨 + 远景墨山（`InkWash`）；滚动浮现由 `ScrollReveal` 控制；
- 开屏：红线沿真实 logo 轮廓描摹 + 粒子笔尖 + 印章 + z 轴环绕，详见 `src/components/Splash.tsx` 与 `src/components/fx/logoOutline.ts`；
- 不显示滚动条，列表/横向滚动仍可手势操作。


## 与桌面端的视觉分工（2026-11 第六版）

- 桌面端：粉紫科技风 + HUD、扫描光、电路线、指针光斑、滚动字幕；
- 移动端：恢复到之前的品牌红渐变 + 极光粒子 + 滚动字幕风格，保留滚动浮现、隐藏滚动条；
- 开屏：红线沿真实 logo 轮廓描摹 → 印章 → z 轴环绕；
- 两端主题色各自独立且均可自定义，不会被写死颜色覆盖。
