# 答题卡制作（模板工坊）

本页是「试卷 → 制作答题卡」的主入口，路由 `/#/papers/studio`；精调页 `/#/papers/:id/edit`，
打印页 `/#/papers/print`（本地/暂存卡片）或 `/#/papers/:id/print`（已保存试卷）。

## 为什么重做

旧设计器（v2 自由画布）把正反两页合并进同一张画布、坐标单位混用 mm 与画布单位，
元素越界、题区重叠、打印尺寸对不上等问题难以根治。新方案：

- **数据只保留标准 v1**：编辑器直接维护 `canvas / markers / blocks / questions / barcode / answerKey`，
  不再做有损的 v2→v1 编译；
- **1 画布单位 = 0.7mm**：A4 竖版 300×424.29，A3 横版 600×424.29，与官方文档示例一致；
- **打印用 mm 排版**：屏幕预览、打印页、编辑器共用同一个渲染器，打印缩放 100% 即为原尺寸；
- **排版引擎保证约束**：自动检查越界、重叠、定位块数量、选项比例、答案键引用，容量不足时先压缩再升纸型。

## 模板

`src/lib/card/catalog.ts` 在原有普高 / 职教命题规格上自动展开，并新增中考系列：

| 体系 | 来源 | 模板数 |
|---|---|---:|
| 普高 | 9 科 ×（标准版 + 换纸型版） | 18 |
| 职教 | 8 个专业/文化课 ×（标准版 + 换纸型版） | 16 |
| 中考 | 复用普高科目，题量 ×0.82、作答区 ×0.78 | 18 |
| 通用 | A4/A3 空白答题卡 | 2 |
| **合计** | | **54** |

`npm run templates` 会导出：

```
templates/
├─ papers/*.paper.json      # 标准 v1 试卷 JSON（可灌入后端 papers 表 / 答题卡模板目录）
├─ designs/*.design.json    # 前端设计文档（含渲染附加信息）
├─ index.json               # 模板清单
└─ README.md
```

后端 `GET /api/v1/templates` 收录的模板会显示在工坊左栏「后端模板」中；
名称能匹配内置模板时按内置规格重排，否则直接以它的内容进入精调。

## 排版规则（generator.ts）

1. 页面按毫米计算：A4 竖版 / A3 横版；四角定位块固定在页边距内（7×7mm）；
2. 表头依次为：考试名称（红）→ 科目标题 → 考生信息 → 注意事项 → 填涂样例 → 条形码占位；
3. 客观题按「分组标题 + 每行 N 题（题号 + 选项框）」排，自动均衡行数（避免 10+2 孤行）；
4. 主观题分栏（A3 三栏 / A4 一栏，必要时自动双栏），逐级压缩行距直到全部可容纳；
5. 容量不够时自动升级纸型（A4→A3）并在页面顶部给出提示，保证不越界、不重叠；
6. 主观题只保存 `region + score`；横线 / 作文格由本机 `qmeta` 渲染，不污染后端 JSON。

## 精确坐标修正

精调页支持：

- 拖动题区 / 文本块，四角缩放手柄，0.5mm 吸附；
- 方向键微调（Shift ×2），Ctrl+Z / Ctrl+Shift+Z 撤销重做；
- 右侧数值面板按 mm 编辑 X/Y/宽/高，题号、类型、分值、选项、文本样式；
- 实时校验面板：越界、重叠、选项比例、定位块、答案键，一键定位到问题元素。

## 保存与识别

- 保存到后端只提交标准 v1 字段：`PUT /api/v1/papers/{id}` + `PUT /api/v1/papers/{id}/answers`；
- 设计附加信息（meta / qmeta / bmeta）只存本机 `localStorage`，不会触发后端白名单校验；
- 后端不可用时仍可本地精调、导出 JSON、打印 / 存 PDF、存为自制模板；
- 识别链路（`POST /api/v1/papers/{id}/check`）按 `choices[].region` 相对题区采样，因此编辑器把
  `choices` 永远约束在 0–1 且整体随题区移动。

## 文本出卡 DSL（借鉴 AFObject/Sheeter 思路）

页面：`/#/papers/dsl`，解析器在 `src/lib/card/dsl.ts`。

```
# A3 / #split 3
# 2026年普通高等学校招生全国统一考试
## 数学 答题卡
### 一、单项选择题（1–8题，每小题5分）
1. X-4        // 单选，4 个选项
2. T-1        // 填空，1 行
3. L-8        // 解答题，8 行横线
4. B-3        // 数字涂卡 [1][2][3]
5. J-5        // 空白作答区
```

解析后走与模板工坊相同的 CardDoc/渲染/校验/保存链路，可继续进精调或打印。

## PS 式精调（react-moveable + Selecto）

- `react-moveable`：拖动、8 向缩放、文本块旋转、吸附与参考线；
- `Selecto`：空白区域框选多选，Shift 追加选择；
- 自定义：顶部/左侧 mm 标尺、图层列表与显隐、对齐/分布工具、Ctrl+A 全选、方向键微调；
- 所有位移最终换算回 mm 并写进标准 v1 的 `region`，不会改变识别口径；
- 文本块旋转保存在本机 `bmeta.rotate`，只影响打印，不进入后端。

> `react-guides` 依赖 React 16 且包内引用了 scss，和 React 19 / Vite 构建不兼容，已移除；
> 参考线直接用 Moveable 自带的 `elementGuidelines` + `snapDirections` 实现。
